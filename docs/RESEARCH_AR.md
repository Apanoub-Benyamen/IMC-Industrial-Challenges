# مصادر البحث وقرارات التسجيل

تاريخ المراجعة: 16 نوفمبر 2026. المصادر الرسمية أدناه تدعم تسمية المستندات وسياقها؛ لا تُعد كل شروط خدمة حكومية مختلفة شروطًا تلقائية لهذه البوابة.

| المسألة | المرجع | القرار في النسخة |
|---|---|---|
| اسم المستند الضريبي | دليل IMC ومصلحة الضرائب | البطاقة الضريبية، مع حقل رقم التسجيل الضريبي |
| وثائق تسجيل منشأة لدى المركز | كتيب IMC الرسمي | سجل تجاري وبطاقة ضريبية وسجل صناعي |
| تفويض مقدم الطلب | إرشادات خدمات التنمية الصناعية والسجل التجاري | صفة مقدم الطلب صريحة؛ التفويض/التوكيل مطلوب عند اختيار مفوض؛ يراجعه المسؤول |
| الشركة ومصانعها | تصميم المشروع | مستندات الشركة مرة واحدة، سجل صناعي مرتبط بكل مصنع |
| التأمينات والقوائم المالية | كتيب المركز يتضمن مستندات تأمينات وقوائم لآخر 3 سنوات | لا تُفرض كشرط عام لتسجيل تحدٍ دون اعتماد المركز؛ يمكن طلبها كمستند إضافي حسب الخدمة |
| رخصة التشغيل | خدمة السجل الصناعي بهيئة التنمية الصناعية | مستند إضافي اختياري في البوابة؛ لا نخلط إنشاء سجل صناعي جديد بالتسجيل في هذه المنصة |
| أحجام المنشآت | اتفاق المشروع | نطاقات مبيعات للتحليل؛ ليست حكمًا قانونيًا أو شهادة أهلية |
| حالات الطلب والاعتماد | خطة المرحلة الأولى وقرارات UX | تصميم مقترح قابل لاعتماد المركز، وليس إجراءً منشورًا من جهة حكومية |

## قرارات تحتاج اعتماد المركز قبل الإطلاق

قائمة المستندات النهائية وحداثتها وصلاحيتها؛ إثبات صفة الممثل القانوني؛ قواعد قبول منشأة دون سجل صناعي في ظروف خاصة؛ هل يحق للشركة امتلاك أكثر من حساب؛ ضبط قاموس الأنشطة والمناطق؛ معايير قبول/رفض الطلب؛ مدة الاحتفاظ ومسار التصحيح والحذف؛ مدة الاستجابة؛ الصياغة الرسمية لاستخدام شعار المركز والوزارة. لم تُخترع موافقة حكومية أو تمويل أو مدة استجابة ملزمة.
