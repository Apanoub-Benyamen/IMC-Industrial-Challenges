# منصة التحديات الصناعية — المرحلة الاولى

[English](README.md) · [خطوات الرفع على GitHub](docs/GITHUB_AR.md)

مشروع كامل بواجهة عربية وانجليزية، وخادم Node.js وقاعدة SQLite تحفظ بيانات المنشآت والمصانع والطلبات والمستندات. هذا هو الكود الكامل حتى تحديث 8، ولا يحتاج الى تنزيل حزم npm.

تحديث 8 يميز الحالات باللون والاسم والايقونة. دليل رفع الكود وتشغيل الموقع برابط مباشر موجود في [دليل GitHub وRender](docs/HOSTING_AR.md).

## التشغيل

ثبت Node.js 24 او احدث، وفك الضغط بالكامل، ثم افتح `start_windows.bat`. افتح http://localhost:3000 واترك نافذة التشغيل مفتوحة.

او من الطرفية داخل مجلد المشروع:

```sh
node seed.mjs
npm start
```

اول تشغيل ينشئ قاعدة محلية وبيانات افتراضية للتجربة. اذا كانت هناك حسابات بالفعل، يحافظ السكربت عليها ولا يعيد ادخال البيانات. خانات الدخول فارغة ولا يختار الموقع حسابا تلقائيا.

| الحساب | البريد | كلمة المرور |
|---|---|---|
| المصنع | factory@imc-demo.test | Factory@IMC2026! |
| ادارة المركز | admin@imc-demo.test | Admin@IMC2026! |

هذه الحسابات تعمل في القاعدة المحلية الجديدة. التحديث لا يعيد كلمات المرور التي سبق تغييرها. اختبر الحسابين في نافذتين منفصلتين او استخدم تبديل الحساب من قائمة حسابي.

## الموجود في تحديث 7 و8

- ترويسة فاتحة بالوان الهوية، وزر القائمة اعلى القائمة الجانبية، دون زر مركز الاجراءات في الترويسة.
- مركز الاجراءات هو بداية عمل الادارة: ملفات الاعتماد والمصانع الجديدة والطلبات ورسائل الدعم التي تحتاج متابعة.
- ملف المنشأة مقسم الى بيانات قانونية، مقدم الطلب، مستندات المنشأة، وبطاقة لكل مصنع بها موقعه ونشاطه ومستنداته. قرار الاعتماد في مساحة مستقلة، ويختفي عند اكتمال الاعتماد دون مصانع جديدة.
- صفحة الطلب بها ملخص اصلي للقراءة، اجراء للمركز، استكمال بيانات، ملفات، مراسلات، ومتابعة مشروع بعد الاسناد. يظهر ما يحتاجه المستخدم في المرحلة الحالية؛ خانات اجراء المركز تتغير حسب القرار المختار.
- يمكن ارفاق خمسة ملفات مع رد الاستكمال نفسه. يحفظ الرد وملفاته معا ويرتبط كل ملف بالرد، ويظهر ايضا في ملفات الطلب.
- المرفقات العامة داخل قسم ملفات الطلب، مع مصدر الملف وتاريخه وامكانية فتحه. الاضافة تظهر عند طلبها.
- حالة الاعتماد هي الحالة الفعلية: مطلوب استكمال يبقى كذلك حتى تعيد المنشأة ارسال الملف. يظهر سجل القرارات والاسباب واعادة الارسال في ملف الادارة.
- المسودات فقط تنقل الى سلة المحذوفات بتأكيد، ويمكن استعادتها او حذفها ومرفقاتها نهائيا بتأكيد ثان. الطلب المرسل يحتاج طلب اغلاق يقرره المركز. الطلبات المحلولة والمغلقة تبقى محفوظة في سجل الطلبات.
- دعم عام بدون تسجيل يطلب الاسم والمحمول والبريد والاستفسار، ويعطي رقما مرجعيا. يصل الى صندوق دعم الادارة مع بيانات التواصل. لا يستطيع الزائر قراءة رسائل مستخدمين اخرين.
- دليل استخدام مستقل للمصنع وللادارة، ودليل بداية للزائر.
- زر اظهار كلمة المرور خارج مربع الكتابة. خيار اخرى للمركز والمنطقة الصناعية، والزام كتابة القطاع والنشاط الفرعي عند اختيار قطاع اخر. نطاق الموقع منفصل عن النشاط حتى يظل القطاع والنشاط الفرعي متجاورين.
- الاحتفاظ باستمارة الطلب المتفرعة وبحث المنشآت والطلبات وفلاتر التاريخ وتصدير Excel وCSV والعربية والانجليزية.

## البريد والمحمول والدعم العام

تأكيد ملكية البريد والمحمول ورسالة التفعيل ما زالت مؤجلة في التشغيل المحلي الافتراضي، وفقا للاتفاق. التسجيل الكامل يصل لانتظار اعتماد المركز، ويستطيع المستخدم الدخول لمتابعة ملفه. تقديم التحدي يحتاج اعتماد المنشأة والمصنع. لا يتم تسجيل البريد كمؤكد لمجرد ادخاله.

استفسارات الزوار تصل فعليا الى قاعدة البيانات وصندوق دعم الادارة. يمكن للمسؤول فتح بريد الزائر او الاتصال به من الازرار، ثم توثيق متابعة داخلية. هذه الملاحظة لا ترسل بريدا تلقائيا للزائر. رسائل حسابات المنشآت المسجلة تبقى محادثة داخل الحساب مع التنبيهات المعتادة.

## تحديث نسخة موجودة والحفاظ على البيانات

1. اوقف الموقع وخذ نسخة احتياطية من مجلد المشروع وهو متوقف.
2. ادمج ملفات تحديث 7 فوق مجلد المشروع الحالي ووافق على استبدال الملفات المتطابقة. لا تحذف مجلد `data` ولا ملف اعداداتك.
3. شغل الموقع من جديد. ينفذ تحديث قاعدة البيانات تلقائيا دون حذف الحسابات او تغيير الاعتمادات او مراجع المستندات.
4. اضغط Ctrl+F5 في المتصفح.

يمكن استخدام الحزمة الكاملة في مجلد جديد. اذا اردت نفس حساباتك وطلباتك السابقة، انقل نسخة من مجلد `data` القديم الى جذر المشروع الجديد وهو متوقف قبل اول تشغيل.

تفاصيل التعديل في [دليل تحديث 7](docs/UPDATE_V7_AR.md)، وقاعدة البيانات في [دليل قاعدة البيانات](docs/DATABASE_AR.md).

## GitHub ومشاركة المشروع

[افتح خطوات الرفع والـ Push](docs/GITHUB_AR.md). ملف `.gitignore` يستبعد قاعدة البيانات والمرفقات وملفات الاعدادات المحلية. الحزمة لا تحتوي بيانات جلسات او مستندات المستخدم.

GitHub يحتفظ بالكود. GitHub Pages لا يشغل خادم Node.js او قاعدة SQLite. يستطيع زملاؤك تنزيل المشروع وتشغيله، اما رابط مشترك يعمل بكل الحسابات والبيانات فيحتاج استضافة لخادم مع تخزين دائم. لم يتم نشر المشروع في هذه الخطوة.

## النطاق

تسجيل جهة في دليل الشركاء يتيح اختيارها عند اسناد الطلب؛ لا ينشئ لها حساب جامعة ولا يرسل مستندات المصنع تلقائيا. بوابة الجامعة وادارة المشروعات الخارجية والتمويل والربط المباشر مع Power BI ليست ضمن هذا التحديث. قبل التشغيل الفعلي راجع [دليل التشغيل](docs/OPERATIONS_AR.md) واعدادات البريد وفحص المستندات وHTTPS الخاصة بالمركز.
